# Spider Solitaire

A fully playable browser-based Spider Solitaire game.

## Features
- 1-suit, 2-suit, and 4-suit modes
- Legal Spider Solitaire card movement
- Stock dealing
- Undo
- Hint system
- Move counter and score
- Completed-run tracker
- Win and game-over detection
- Responsive dark interface

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. GitHub will provide a public URL after deployment.
