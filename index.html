How to Play

  • Move face-up cards onto a card exactly one rank higher, regardless of suit or color.
  • You can stack mixed suits, but a multi-card run can move together only when it is descending and all cards in that run are the same suit.
  • An empty column can accept any movable card or valid same-suit sequence.
  • Click the stock to deal one new card to every column. You cannot deal while a column is empty.
  • A complete same-suit King-to-Ace run is automatically removed.
  • Remove all eight runs to win.
